A tiny program that writes one painfully honest out-of-office reply, polite on the surface and true underneath.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or to `/tmp/out/entry.txt` when that variable is not set.
